## Description:

darwin-skill helps agents assess and improve an existing SKILL.md through scoring, targeted edits, testing, validation, and retention or rollback.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dxy0905](https://clawhub.ai/user/dxy0905)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and skill maintainers use this skill to review and improve a single agent skill instruction file with structured scoring, validation, and human confirmation before changes are retained.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is intended to evaluate and modify skill instruction files, which can affect future agent behavior.

Mitigation: Provide the exact target SKILL.md, review the diff and test results, and require human confirmation before retaining changes.
