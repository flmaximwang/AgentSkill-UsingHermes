# 信用卡与信用工具的负债余额

配合 SKILL.md 的「信用卡/信用工具的余额勾稽」一节。数据文件：
`Asset Balance/信用卡账单.tsv`（人工维护：账户 / 账单日 / 账单金额 / 到期还款日 / 来源 / 备注 /
账单金额(美元)；账户必须是负债科目）。命令：`python -m Scripts balances`。

**两张人工表都用 TSV（制表符），不用 CSV**：口径/备注里常有半角逗号（`1,860.79`、`总资产,含美元`），
CSV 下会被 Excel 拆列、手写还得加引号；资产表同理（`Asset Balance/资产表.tsv`）。

## 三个口径什么时候用

| 口径 | 用途 | 不能用来干什么 |
|---|---|---|
| 账单口径 | 回答「还欠多少已出账的钱」 | 当资产表余额（少算未出账消费） |
| 综合口径 | **资产表的负债行**（真实欠款） | —— |
| 账本口径 | 与账本 2241 余额对照 | 当余额（漏掉没进流水的消费） |
| 账单未覆盖 | 查「某张卡的消费是否被漏记」 | 当错账（它只是提示） |

期初按 0 的前提：账单**从该卡第一张开始给**。代码在「账单台账起始早于账本首笔记录」时会提示。

## 账单周期怎么定（不猜，从数据推）

- 账单日各卡不同；周期 ≈ 上月账单日+1 ~ 本月账单日。
- 用「还款额 = 上一张账单」验证周期与账单可靠性（0270：7/3 还 1,860.79 = 0616 账单、
  8/4 还 2,057.43 = 0716 账单，一分不差）。
- 周期消费合计与账单**不会完全相等**（差几十元）：卡的记账日与平台交易日差 1–2 天、个别笔跨了周期
  边界。**不要为凑平去改周期定义**，也不要把这种小差当错账。
- 某月账单**明显**大于账本消费（上千元）→ 不是边界问题，是漏记的消费，按「账单未覆盖」报出来。
- 账单带**美元**子余额时单列不换算（账本是人民币口径、没有汇率凭据），进「账单金额(美元)」列。

## 还款侧也会缺：账本口径为负的第二种成因

账本口径为负 = 流水里看到的还款 > 消费，两种成因：

1. **期初欠款**（起账之前欠的，当年还掉）—— 正常；
2. **还款来自没有导出流水的卡**（工行 8935 / 农行 4077 / 网商 0026 / 广发 0675）→ 那些还款我们看不到，
   推导出的欠款必然偏高。量级：`账单合计 − 流水里的还款`（9393 约 2,700）；真伪只能问用户
   （「有没有从这几张卡还过款」）。

**结论**：用户能读到「未还余额」就用人工值（9393 → 1,022.23 + 美元 20 单列），推导值只当对照；
读不到才只给账单（0270 的还款与账单一分不差 → 推导可信）。人工值录入后，同一张卡不再同时出推导值。

## 负债科目体检：分清「期初欠款」与「消费缺失」

读各期账本「统计」表逐明细的**本期增加/减少**并累计：

- 累计**增加 = 0**（只有还款）→ 消费根本不在四个来源里（美团月付这类平台自营信用支付：
  四个来源里 0 条「月付」结算方式）→ 余额必然是负的，只能挂负数或把还款当费用；
- 累计**增加 > 0 但净变动为负** → 大概率是**期初欠款**在当年被还掉（美团借钱 −30,385.07、
  花呗 −2,866.55、京东白条 −2,673.80）—— 正常，不是记错；
- 两者都要外部锚点才能定案：**上年末各负债账户未还余额**（＝当年期初）。有期初之后
  「期初 + 账本净变动 = 期末」就能跑，差额自己指出哪个账户的消费没进流水。

## 脱敏的银行侧还款/扣款怎么认（双侧留痕，不靠字样）

建行只留户名最后两字：`4******9202/***月付`、`Z******0016/***还款`。

- **判归属靠双侧留痕**：花呗还款**一定**在支付宝账单里成对出现（`中行卡 out` +
  `支付宝 neutral`，摘要「花呗主动还款-YYYY年MM月账单」）→ 平台侧没有同额同日行就**不是**花呗；
- 再用**金额合理性**兜一道：她的花呗消费总额只有 16.92，就不可能还 748.68；
- 美团月付的消费**不在四个来源里**（美团 App 自己的信用支付）→ 只有还款没有消费；
- 最终定案只看**银行 App 的交易详情**（App 不脱敏、PDF 才脱敏）。归属未定时，账上先挂在证据
  支持度更高的那个明细，并在注释里写明「未最终证实」，不要写成已确认。

## 报给用户的定位值（他说「找不到这笔」时）

给「日期 + 金额 + **交易后余额** + 对账单序号 + 哪个文件」，并点明是**哪张卡**（谁的卡）——
四个值凑齐一次就能在 App 里找到；只给日期金额他会找不着。
