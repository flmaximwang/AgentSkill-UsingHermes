# 中国电商/内容站：规格与价格提取

适用场景：需要某款国内在售商品的**官方参数、实测数据、在售 SKU 与价格**（消费电子、家电、音频等）。

## 站点速查

| 站点 | curl 直取 | web_extract | 可靠取法 |
|---|---|---|---|
| **苏宁 itemcanshu** suning.com/itemcanshu/0000000000/<id>.html（及 suning.com/item/…） | ✓ | ✓ | **国内家电参数首选**：服务端渲染完整参数表——品牌 / 型号 / **产地** / 外观材质 / **接触食材材质** / **CCC 认证编号** / 净重 / 容量 / 额定功率 / 上市时间。在这些字段上比京东能拿到的多得多 |
| 知乎 zhuanlan.zhihu.com / zhihu.com/tardis/bd/art/<id> | ✗ ~700 B 空壳 | ✓ | **一次只传 1 个 URL**；批量会整批 `Extract timed out after 120s via parallel` |
| 京东 item.jd.com/<sku>.html、mall.jd.com 店铺页 | ✗ 桌面端经常**直接跳登录页**（返回的是登录表单，不是商品） | ✗ | 改用移动端 `item.m.jd.com/product/<sku>.html`（iPhone UA）——但那里也只有标题与页面骨架，**「商品参数」「评价」仍由 JS 注入**；参数去苏宁或搜索结果摘要拿 |
| 京东价格 | ✗ 价格由 JS/登录态注入，匿名价格接口不可直取 | — | 带日期的行情稿（ZOL）或搜索摘要 |
| 淘宝 taobao.com/list/item/…、detail.tmall.com | ✗ ~3 KB 反爬壳 | ✗ | 搜索摘要常含渲染后的「标题 + ¥价格」，引用时标"未实时核验" |
| 中关村在线 dcdv.zol.com.cn / detail.zol.com.cn | ✓ 但 **GB18030** | ✓ | curl + `decode('gb18030')`（utf-8 出乱码）。⚠️ **型号↔页面会错配**：行情稿标题写的型号，跳过去的参数页可能是完全另一个品类（实例：标题为「某品牌 4L 空气炸锅」的参数页实为「单灶电陶炉 / 微晶面板 / 1355W」）。引用 ZOL 参数前，必须用第二个来源确认该页面确实属于该型号 |
| 搜狐 / 网易 / 什么值得买 | ✓ | 部分（smzdm 正文需 curl） | curl + 去标签后按段落输出 |
| 品牌官网（syitren.com 等） | ✓ | ✓ | **首选**：官方规格表 + 官方定价（常含 USD） |

## 京东移动端元数据（有尺寸重量，无价格）

```bash
curl -sL -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 Mobile/15E148 Safari/604.1" \
  "https://item.m.jd.com/product/<sku>.html" -o /tmp/jd.html
```

HTML 内 `window._itemInfo = ({ ... })` 含：`product.skuName` / `color` / `venderId` / `category`，以及
`product.width/height/length`（mm）与 `product.weight`。

**口径规则**：这四项是**物流箱尺寸与含包装毛重**，不是整机尺寸/净重。写进对比表必须标注口径，否则结论失真。

## 参数来源优先序（家电/3C）

苏宁 itemcanshu 参数页 → 品牌官网规格表 → 搜索结果摘要里渲染出的参数片段 → 移动端京东（仅标题/骨架）→ ZOL（**须先核对型号身份**）。

搜索结果的 description 常携带整页渲染后的参数文本（"品牌：X；内锅材质：Y；额度功率：Z"），定位阶段很好用，但引用时仍标"未实时核验"。

## 核验锚点

- **CCC 认证编号**（苏宁参数页给出）= 隐形的"是否同款"锚点：同款在别的渠道/店铺应给出同一编号。
- **产地**能把同一品牌拆成多条代工线：同一品牌横跨多个代工城市 = 拼盘品牌，需逐型号核参数。
- **上市时间**字段能识别"老平台仍在售"（非当期主推）。

## 价格纪律

- 每个价格带 **来源 + 日期**；同一机型跨渠道价差可达 2 倍（京东自营 / 淘宝第三方 / 台湾 momo NT$ / 海外 USD）。
- 京东自营价常见于 ZOL 行情稿形式："原价 X 元，活动/国补/券后到手 Y 元"——引用时保留日期与"到手价"口径。
- 台湾 momo（NT$）与海外官网（USD）价格**不能当大陆价**，只能作横向参考。
- 抓不到实时价时明确写"未能核实实时价"，不要用挂牌价冒充到手价。

## AI 生成内容的识别与降级

- 知乎文章页会标注「内容疑似 AI 生成」；搜狐号/网易号转载常带「本文包含人工智能生成内容」。
- 这类文章的参数表与频响曲线数值**可能自相矛盾**（同一机型一处 1W+1W、另一处 2W 单喇叭）。处理：并列报告冲突，**不取平均、不择一当结论**，整体降为"定性参考"。
- 快懂百科（baike.com）类词条给参数但不给来源 → 等级低于官方规格表与实机长测，引用时标"未获官方证实"。

## 取值顺序

品牌官网规格表 → 实机长测（什么值得买社区长测 / B站续航实测 / chiphell 长文）→ 电商元数据（尺寸、重量、在售 SKU、店铺）→ 带日期的媒体价格稿 → 搜索摘要里的第三方挂牌价。
