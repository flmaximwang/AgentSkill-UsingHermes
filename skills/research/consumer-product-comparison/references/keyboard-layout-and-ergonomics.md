# 键盘 / 外设：配列命名、判断轴、比值区间

比价前先把用户的品类词对到社区标准名（见 SKILL.md Step 0.2）。

## 命名映射

| 用户口语 | 社区标准名 | 形态定义 |
|---|---|---|
| 斜配列 / 斜配键 / 斜键 | **Alice 配列**（一体式时） | 一体式，左右两半各内旋，中间留空放旋钮/铭牌 |
| 非错行 / 竖排 | **直列 / 正交（ortholinear）** | 纵列对齐，取消行内 1/4 错位 |
| 分开两半 / 左右手分开 | **分体式（split）** | 物理两半，可有 tent 与可调角度，拇指区 3–6 键 |
| 98 / 87 / 75 / 65 / 60 | **百分比配列** | 键数等级，与轴体、外壳结构无关 |

「配列」= layout（键位排布），不是轴体也不是外壳结构；卖家文案常把三者混为一谈。

## 决定满意度的量（按筛选手顺）

1. **配列完整性（F 行有无）** — 75% 有独立 F 行（常另带左侧 Macro 区），65% 没有。以敲代码/重度快捷键为主用途时这是硬门槛：先按它筛候选，再比材质、结构、价格；65% 款再好看也不进主力档。
2. **形态解决什么** — Alice 两半内旋角实测约 6–10°（TGR Alice ≈8°、Sneakbox AVA 6°、带 tent 的 ergo 款 7°+5°），只改善手腕尺偏与肩内旋；一体式 Alice 基本没有 tent，拇指区只有分裂空格（分体式才有 3–6 个拇指键）。要解决手掌旋前或要拇指键 → 跨到分体式：这是**品类差异**，写进一句话结论，不是脚注。
3. **前高** — 常规轴 Alice 主流 18.7–20.7 mm（无键帽口径），后高可到约 30 mm。前高越高越需要掌托：把「是否含掌托 / 掌托单价」计入比较，别把掌托当赠品。矮轴款前高更低但键程不同，**不要和常规轴款混排一栏比手感**。
4. **连接与电量** — 三模（有线 + 2.4 G + 蓝牙）是该价位标配，电池常见 3000–8000 mAh；2.4 G 与蓝牙的回报率/延迟数字要标来源。
5. **固件与改键** — QMK/VIA（自由改键、多层映射）vs 私有驱动（如 Akko Cloud Driver）。重度用户按硬需求处理：不能 QMK/VIA 的直接降级。

## 比值区间（标注为「本人计算」，入表须标「成品 / 套件」口径）

- **元/键**：塑料壳成品 ≈4–6；铝坨坨成品 ≈9–11；铝坨坨套件（无轴无键帽）≈4–5。
  同一键数下成品与套件几乎差一倍 —— **口径不标，性价比结论会反向**。
- **电量密度 mAh ÷ 元**：≈6–18（大电池 + 低价款最高，与「贵 = 续航好」的直觉相反）。

比值用 execute_code 算，不要心算。

## 取价路径（CN 外设）

1. 品牌官网（含海外站）拿硬参数与官价；国行首发/促销价常低于海外 USD 官价一档以上，两者并列报告。
2. 带日期的中文快讯拿 CN 到手价：IT之家、in外设、ZOL、什么值得买。
3. 电商搜索摘要若带价格文本可作数据点，标「未实时核验」。
4. 排除：贸易/AI 聚合站、自标「由智能模型自动生成」的榜单、内容站模板页（只渲染站内导航无正文）、只给标题不给价的「list」页。
