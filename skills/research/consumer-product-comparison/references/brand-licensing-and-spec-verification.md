# 品牌性质核验与参数落地（中国厨电/小家电）

适用：用户问"X 牌的这个东西怎么样"。在中国消费电子/厨电语境里，**品牌名不等于制造商**，也不构成产地、技术或质保的承诺。

## 一、先分三类品牌

| 类型 | 判据 | 对结论的影响 |
|---|---|---|
| 自有品牌 | 品牌方自己设计/制造/售后，官网列本品类，保修主体是品牌方 | 可以按品牌谈 |
| 商标授权（贴牌） | 品牌所有者已退出该品类，商标授权给第三方，产品由代工厂做 | 品牌溢价买的是标签；售后主体是授权方/代工厂，不是那个知名公司 |
| 傍名牌/同名不同主体 | 同名公司在国内注册，与国外同名品牌无授权关系 | 必须提示用户向卖家核实授权方，不要替它背书 |

## 二、30 秒识别动作

1. 搜 `"<品牌>" 商标 授权` / `"<品牌>" used under license`。
2. 读品牌方的**公司官网**（不是商品页）的业务范围，确认它**今天**还做不做这个品类。
3. 找授权声明字符串——授权方页面页脚常见：`X® is a registered trademark of Y used under license by Z`。找到它，就等于拿到"品牌 ≠ 制造商"的一手证据。
4. 查该品牌在中国的运营主体（旗舰店页脚常有公司名），与品牌方是否同一实体。
5. 看同一品牌在售品的参数是否分裂（见第三节）——分裂即拼盘。

## 三、参数分裂 = 多授权线/多代工厂

收集同一品牌在该品类下的多个型号，逐列比对；只要有 2 列以上不一致，就按拼盘处理：

| 列 | 为什么重要 |
|---|---|
| 产地 | 同一品牌横跨多个代工城市 ⇒ 多条线 |
| 接触食材/腔体材质 | 同一品牌既有玻璃又有铝合金不粘涂层 ⇒ 卖点不统一，"无涂层"别默认 |
| 型号前缀 | 多套前缀（如 `WK-` / `CB-` / `IB-`）通常对应不同授权方 |
| 控制方式 / 功率 | 跨度异常 ⇒ 不同平台拼装 |
| 上市时间 | 数年前的老平台仍在售 ⇒ 非当期主推 |

**推论规则**：品牌级问句的结论必须落到"具体型号 + 该型号参数页"，因为品牌内的差异可能大于品牌间差异。

## 四、必核字段清单（厨电/小家电）

从**参数页**取（不是标题、不是详情长图），缺失就向卖家问：

容量(L) / 额定功率(W) / 温控范围(℃) / 接触食材材质与涂层 / 产地 / CCC 认证编号 / 净重 / 上市时间 / 保修年限与主体 / 能否进洗碗机 / 最易污染部位是否可拆洗。

→ 用容量与功率算 **功率密度 W/L**，与品类主流区间比（见 SKILL.md Step 0.6）。

## 五、卖家必问清单（可直接抄给用户）

1. "接触食材的部位到底是不是全玻璃 / 全不锈钢？具体材质是什么？"（要具体到 高硼硅 / 微晶玻璃(玻璃陶瓷) / 304 / 涂层类型）
2. "抗温差多少度？能不能进洗碗机？碎了 / 涂层掉了怎么保修？"
3. "发热方式是金属发热管还是光波/碳素管？最高温度多少？"
4. "这个产品是不是 <品牌方> 的官方授权产品？授权方是谁？"（同时让用户自己去看品牌官方旗舰店在不在卖该品类——这一步 agent 常因登录墙做不了，要明确交还给用户）
5. "保修主体是谁、几年、寄修还是上门？"

## 六、常见"授权扩张"品牌形态（识别用，不是黑名单）

材料/厨具/老牌工业企业把商标授权给国产小家电厂做品类扩张，同一电商页面里常能同时出现多个此类品牌。**认形态**：名字带"某国"或老牌工业/材料公司色彩 + 参数页产地是国内代工城市 + 型号前缀陌生。看到这种形态默认走本文件流程，不要按"外资大牌"处理。

## 七、证据口径

- 参数页字段（材质/产地/CCC/功率）= 一手可核实，给链接。
- "玻璃不是微晶玻璃"这类由价格量级推出的判断 = **外推**，必须标注，用"据此推断"而不是"官方说明"。
- 找不到该型号的第三方实测时**明说没有背书**；不要用同品类通用评测代替。
- 品牌方商品页文案与参数页冲突时，参数页优先，冲突照报。
