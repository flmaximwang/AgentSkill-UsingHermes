# ABSTRACT

**Abstract**:: Hermes Desktop 是由社区开发者（sir1st）创建的 Hermes Agent GUI 桌面应用，将 Nous Research 的 Hermes Agent 打包为 200MB 的 DMG/EXE/AppImage，使非开发者也能使用。该项目后续迁移至 EKKOLearnAI/hermes-web-ui（原名 Hermes Web UI），发展为功能完整的 Web 仪表盘，支持多平台 AI 聊天、会话管理、定时任务、用量分析等功能。

## 与 Hermes Agent 的关系

- **Hermes Agent**（Nous Research 官方）— 核心 CLI AI 代理框架
- **Hermes Desktop / Hermes Web UI**（社区项目）— GUI 外壳 / Web 仪表盘
- 两者是**核心引擎 vs 社区外壳**的关系，Hermes Web UI 不是官方产品

## 重要链接

- 项目地址: https://github.com/EKKOLearnAI/hermes-web-ui
- 官网: https://hermes-studio.ai
- 早期版本: https://github.com/sir1st/hermes-desktop
